# Homework Bot VK

Бот, который каждые 10 минут обращается к API Яндекс.Практикума и присылает в личные сообщения VK уведомление, как только меняется статус проверки домашней работы.

## Описание проекта

Во время учёбы на курсе Яндекс.Практикум неудобно постоянно заходить на сайт и вручную проверять, взял ли ревьюер работу в проверку и что он написал. Этот бот решает задачу за вас:

- раз в 10 минут опрашивает API Яндекс.Практикума и запрашивает статус последней отправленной домашней работы;
- если статус изменился — присылает сообщение в VK с расшифровкой вердикта («работа взята на проверку», «принята», «есть замечания»);
- если во время работы что-то пошло не так (недоступен API, отсутствуют токены, сетевые проблемы) — логирует ошибку и присылает уведомление об этом в тот же VK-чат;

## Стек технологий

- Python 3.12.7
- [vk_api](https://github.com/python273/vk_api) — отправка сообщений через VK API
- requests — обращение к API Яндекс.Практикума
- python-dotenv — хранение токенов в переменных окружения
- pytest — тестирование
- flake8 + flake8-docstrings — проверка стиля кода

## Как запустить проект

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone https://github.com/<ваш-логин>/homework-bot-vk.git
cd homework-bot-vk
```

Создать и активировать виртуальное окружение:

```bash
python -m venv venv
source venv/Scripts/activate    # Windows (Git Bash)
source venv/bin/activate        # Linux / macOS
```

Установить зависимости из файла requirements.txt:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Создать в корне проекта файл `.env` и заполнить его своими значениями:

```
PRACTICUM_TOKEN=токен_яндекс_практикума
VK_TOKEN=токен_вашего_vk_приложения_или_сообщества
VK_USER_ID=id_пользователя_которому_слать_уведомления
```

- `PRACTICUM_TOKEN` — токен для доступа к API Яндекс.Практикума, выдаётся в личном кабинете курса.
- `VK_TOKEN` — токен доступа VK (сообщества или standalone-приложения) с правом на отправку сообщений.
- `VK_USER_ID` — ID страницы VK, куда бот будет присылать уведомления о статусе.

Запустить бота:

```bash
python homework.py
```

Бот начнёт работу в бесконечном цикле и будет проверять статус домашней работы каждые 10 минут, пока процесс не остановлен.
